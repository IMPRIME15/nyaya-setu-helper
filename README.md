# Nyaya Setu Helper ⚖️

## 📌 Problem Statement
Many people in India are unaware of their legal rights and struggle to access legal information easily. Legal processes are often complex and difficult to understand.

## 💡 Our Solution
Nyaya Setu Helper is an AI-powered web platform designed to simplify legal information and make it accessible to everyone. It acts as a bridge between citizens and legal awareness.

## 🚀 Features
- Easy-to-understand legal guidance
- User-friendly interface
- Quick information access
- Responsive web design
- AI-assisted content generation

## 🛠️ Technologies Used
- React.js
- Vite
- JavaScript
- CSS
- AI tools for UI & structure assistance

## ▶️ How to Run
1. Clone the repository
2. Install dependencies using npm install
3. Run npm run dev
4. Open in browser

## 🌍 Future Scope
- Multilingual support
- Real-time legal chatbot
- Case tracking system
- Government portal integration
